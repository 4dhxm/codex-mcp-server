# Codex MCP Server

A Model Context Protocol (MCP) server that provides programmatic access to Codex agent threads, tasks, and history.

## Features
- Run autonomous coding tasks.
- Create, resume, and fork chat threads.
- List available threads and view metadata from Codex SQLite database.
- Cancel running turns via AbortSignals.
- Archive sessions.

## Prerequisites
- Node.js >= 18
- Codex CLI installed and authenticated
